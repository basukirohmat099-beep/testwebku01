# ARCHIVE-TOOLS

Precision Vector Studio · Closed-Path SVG · Alight Motion Export

## Fitur
- UI modern biru muda profesional & smooth
- **Vector Studio** : Raster → Closed-path SVG (semua path ditutup Z, layer terpisah, ID stabil)
- **SVG → Alight XML** : Setiap closed path menjadi layer animatable terpisah
- Kategori: All / Downloader / Maker / Tools
- Pure static — tidak butuh backend

## Cara Deploy
1. Drag & drop seluruh folder ke https://vercel.com/new (paling aman)
2. Atau kirim zip ke bot setelah GitHub sudah di-connect di Vercel
3. Atau buka `index.html` langsung di browser
